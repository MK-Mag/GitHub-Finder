# Frontend

The GitHub Finder desktop interface is built with Vue 3 and runs inside the Wails v2 desktop runtime.

## Stack

- Vue 3 with Composition API and `<script setup>`
- Pinia for application state
- ApexCharts for repository statistics
- Vite for development and production builds
- UnoCSS remains available in the project dependencies

## Structure

```text
src/
├── App.vue                 # Search, profile, charts, and repository list
├── main.js                 # Vue, Pinia, and ApexCharts setup
├── style.css               # Global design system and responsive styles
└── stores/
    └── GithubUser.js       # GitHub data, loading state, and chart data
```

## Commands

Run these commands from the `frontend` directory:

```bash
npm install
npm run dev
npm run build
npm run preview
```

For the complete desktop application, run `wails dev` or `wails build` from the repository root.

## Backend Integration

The Pinia store calls the Go methods generated by Wails:

- `FetchingUser(username)`
- `FetchingRepoItems(username)`

Keep these method names in sync with the exported methods on the Go `App` type.
